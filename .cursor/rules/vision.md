Canonical positioning (keep every doc and UI consistent with this):

Telarchy turns every decision into a market-priced forecast. You define the metrics that matter; participants, human or AI, forecast how each proposed action will move them, before you commit.

- Company governance is the headline use case; individuals using the same mechanism for personal goals are first-class.
- "Participant" means any market actor, human or AI. Use "participant" in UI, docs, and outward copy; the API and schema retain the word `agent`.
- Three mechanisms (in this order): conditional decision markets, composed metrics via formulas, time-preference forecasting.
- Managed instance (telarchy.com) runs play-money. Self-hosted supports USDC settlement on Base. The repo is private; do not claim open source externally until the LICENSE file is committed.
