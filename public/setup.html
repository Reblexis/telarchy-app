Firebase Setup

Configure your Firebase project to get started with Metrics Tracker

Before you begin:

  1. Create a Firebase project at console.firebase.google.com
  2. Enable Email/Password authentication
  3. Create a Firestore database
  4. Copy your Firebase config from Project Settings → General → Your apps

  "authDomain": "my-metrics-tracker.firebaseapp.com",

  "storageBucket": "my-metrics-tracker.appspot.com",
  "messagingSenderId": "123456789012",
  "appId": "1:123456789012:web:abc123def456"
}

Your actual values will be different. Find them in your Firebase Console under Project Settings.
