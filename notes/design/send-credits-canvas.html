Sending credits to someone else

The API already moves credits between any two participants. The site only lets you fund your own bots. Three places the missing door could go, each one working below: type an amount and press through it. Sample participant, sample numbers.

It cannot be undoneNo reversal exists, so the last press names the amount and the person.
It costs season scoredocs/seasons.md: credits you send count as a loss for you and a gain for them. The form says so while a season runs.
It shows on both recordsThe Transfers section of both profiles gains a row, memo included, so the memo is public.
Never on your own profileAnd a signed-out visitor pressing it goes to sign in, then comes back.
Direction A

A row under the name

The same hairline row /agents already uses for funding a bot, opened by a text action in the header.

  • One pattern for every send on the site
  • Smallest build, nothing new to learn
  • One press sends. Light for something irreversible that costs score
  • Only reachable from the person's profile

Direction B Recommended

The ticket

A pill in the header opens the dialog a trader already knows from buying: big amount, the facts underneath, and a button that asks once more in its own words.

  • The weight matches the act: two presses, amount and name on the second
  • Room for the facts: balance after, season cost
  • Quick amounts, and "All" without typing your balance
  • A dialog where A needs none
  • Still only reachable from the profile (C's menu item can open this same ticket later)

Direction C

From your own balance

Sending starts where your credits are: the account menu opens a small door page, /send, where you name the person. A profile's pill links to the same page with the name filled in.

  • Works from anywhere, no need to find the profile first
  • One form for every send, bots included
  • A new page and a participant search to build and keep
  • Typing a name invites sending to the wrong one; the ticket on a profile cannot
